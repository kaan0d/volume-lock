Rules

Precedence: never touch > exact site > site and subdomains > default volume.

Site and subdomains 0

A pattern like *.example.com covers the domain and all its subdomains. Add one in the Sites table above; an exact site always beats it.

    Never touch 0

    The extension leaves these sites alone, whatever else is saved.

      Start muted 0

      Tabs on these sites are muted when the page loads. Moving to another site unmutes them again.

        02 · General

        Set it once.
        Hear it right.

        Audio

        %

        Boost raises the limit from 100% to the boost limit; a limiter keeps loud peaks from distorting. Turning it off keeps levels above 100% stored, but they play at 100%.

        Boost is one setting for all sites. Each site still keeps its own level.

        %

        Shows a notice in the popup when the level goes above this. It never stops you. 100 to 600, or 0 for no warning.

        Applies to the button on the Other tabs page. "Only tabs muted from the extension" leaves tabs you muted yourself alone.

        %

        During these hours, sites without a saved level start at this level instead of the default. Saved sites are not changed.

        Sound

        Evens out loud and quiet parts, so ads and explosions stop jumping out.

        Sound settings apply to every site you have not excluded, and to media played through Web Audio. Protected (DRM) media and media from another site without CORS stay unchanged.

        Shortcuts

          Chrome keeps the keys. The button opens its shortcuts page.

          Backup

          Replace all current settings with this file?

          Delete every saved site? Default, boost and the never-touch list stay.
